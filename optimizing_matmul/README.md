This is a 3 hour-ish exercise in trying to optimize a matmul kernel with AI help for implementation. The idea is to be able to call all the shots algorithmically, but have the AI do experiments. This is on a single H100.

To begin with, I will be optimizing only multiplication of NxN matrices where N is a power of 2 and I use the "naive algorithm" (i.e. no Strassen, alphatensor like https://deepmind.google/blog/discovering-novel-algorithms-with-alphatensor/, etc...). This makes hte algorithm O(N * N * N); specifically it was N * N * N multiplications and the same number of additions---naively this is `2N**3` flops. If we set N to around a thousand we spend around 2 billion FLOPs. Since we are using an H100 (specs below) it has at most 1.979K teraflops (trillion flops) using bf16 (we will use bf16), to spend around 1 second we should increase teh computational size by around one thousand; the easy way to do this is to grow each axis of each matrix by a factor of around 10, so `N=8092=2**13`.
